Sign in

Starts from: Opening the app. An account is required before anything else; there is no browsing without one.

Email, then a password or a one-time code. Everyone creates a password when they sign up. Returning users log in with it or get an emailed code instead. No Apple or Google sign-in.
New and returning users share one flow. Returning users go from the code straight back.
Finish the action they tapped after sign-in.
Intention only sets the starting feed. Activity takes over after that.
Marketing texts are a separate opt-in that starts off.
