Dev notes

First launch: sign in

First screen after download. Led by a large studio 3 logo (mark about 280 wide, wordmark 40, shipped as an SVG). Form sits at the bottom in thumb reach. Background: soft, blurred iridescent haze (blue grey, lilac, blush, cream) drifting slowly over about 18s; static with reduced motion. Black logo.
Shown empty: placeholder you@email.com and a grey Continue button that turns Ink once a valid email is typed. Continue sends the one-time code. Phone is optional, asked during profile setup. Then the same code, profile setup and intention steps.
An intro animation is planned for this screen later.
Everyone needs an account before using the app. There is no way to browse first. The Terms and Privacy Policy agreement happens during profile setup for new accounts.
Continue checks the email: a new email goes to the code screen, then profile setup (where they create a password). An existing account goes to Welcome back, where they enter their password or ask for an emailed code instead.
