Dev notes

Insights

Only for seller profiles. Opened from the chart icon at the top right of your own profile (next to More). Collectors never see it.
Time filter as chips at the top (the same chips as Explore): 7 days, 30 days (default), All time. Everything below follows it.
Earned is the main number, large, with See payouts under it (opens Payouts in Settings). No comparison line on earnings. Spacing: 32 between sections, 8 inside them, 14 inside list rows.
Then saves, new followers and collected in three equal columns, each centered, each with its change from the previous period as an actual number right next to it in small grey Geist Mono (412 +64, 38 +6), never a percentage. If nothing changed, show nothing next to the number (no +0). No red or green arrows. No view counts anywhere.
Most saved: up to 5 pieces, ranked by saves, with a 3:4 thumbnail, title, saves (Geist Mono) and status. Tapping a piece opens it.
Events: up to 3, newest first, only if they hosted in the period (hidden otherwise). Tickets sold and check-ins; opens Manage event. No charts for launch.
If fewer than 5 pieces have saves, show only those; with no saves at all, hide Most saved. No See all for launch.
