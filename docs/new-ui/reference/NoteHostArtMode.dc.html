Hosting 1d: event art

Sheet from the Event art row in Details. Four choices: No art, Showing only (on display, nothing sold), Selling (set prices), Auction.
An event is either Selling or Auction, never both. On either, each piece can still be set to Not for sale, so it is shown but not bought.
Selling and Auction events also pick delivery for every sold piece: Pickup at the event or Ships after the event. Buyers do not choose.
Auction events: the host picks when bidding ends, at the latest 30 minutes before the event ends (that is also the default). The end time shows on every auctioned piece.
