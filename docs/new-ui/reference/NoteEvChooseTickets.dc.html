Events 1: choose tickets

Opens as a sheet when someone taps Get tickets on an event page.
Each ticket type the host created is its own card: name, price (or Free), what is included, how many are left, and − / + buttons. People can pick from several types in one order, for example 1 General Admission and 1 VIP. A card with at least 1 ticket picked gets a slightly darker grey border (#B8B8B4); others use the light line color.
When 5 or fewer are left, the count turns red and says Only 3 left. A sold-out type stays as a card in grey with Sold out instead of the buttons. The host's per-order limit stops the + button.
The total updates as they change numbers and is the full ticket price. There is no buyer fee; only tax is added at checkout, so the line says tax added at checkout. The button says Continue to payment. Free (RSVP) events show Free instead of a price and the button says Reserve.
