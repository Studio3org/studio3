How it scales

Margins stay fixed (16, 20 or 24) on every phone. Content widths stretch between them.
Cards follow one of three rules: full width, a percentage of the width, or a fixed width for shelves. Heights always come from the aspect ratio.
Grids stay two columns on every phone. Only the column width changes.
Type does not scale with screen width. Support Dynamic Type instead: text grows, layouts wrap, and nothing gets cut off.
Fixed elements (nav, bottom bars, pinned buttons) sit on the safe area insets, never fixed pixel offsets.
On the smallest phones, screens with pinned buttons scroll their content so nothing hides behind the button or the keyboard.
The mocks round some heights (for example feed pieces at 470). Build from the rules here, not from mock pixels.
