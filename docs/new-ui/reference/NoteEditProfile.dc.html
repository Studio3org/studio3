Dev notes

Edit profile

Opened from Edit profile on your own profile. Cancel throws away changes (ask to confirm if anything changed). Save saves and goes back.
Tap the cover to change it (wide crop, same screen style as other image edits). Tap the photo (pencil badge) to change it (square crop, shown round).
Name. Username: @ is shown in grey, availability checks as they type, and it can be changed once every 30 days (show the date it can next change if locked).
Bio: up to 150 characters with a live count in Geist Mono. Location: city only, opens the same city picker as posting. Website is an optional link shown under the bio. No social media links.
Not here: email, password, phone, payouts (all in Settings). The upcoming show card on a profile comes from events automatically and is not edited here.
Mediums: optional, only shown for seller profiles. Opens the same medium list as posting; pick up to 3, in order (the first is their main one). Shows as one line of small text under their username on the profile (Painting · Mixed media) and is used for Explore's Artists to know and search by medium.
Mediums only shows for people with a seller profile.
